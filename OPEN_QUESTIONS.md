# Open questions — Corrections Pest Reference

Each item stays open until a primary source closes it. No page asserts an answer before then.
The same list is published on /methodology/#open-questions.

1. **OSHA coverage of public employers.** Which states run an OSHA-approved state plan covering
   state and local government employees (osha.gov/stateplans); whether Utah's plan (UOSH) covers
   county and state correctional employers and adopts 29 CFR 1910.141 by reference (Utah Admin.
   Code R614, verbatim adoption language). How federal (BOP) and privately operated facilities
   are covered. Closes the pending line on /authorities/osha-1910-141-sanitation/.
2. **Food code reach into correctional kitchens.** FDA Food Code 2022 §1-201.10(B) "Food
   establishment" definition verbatim; per state, whether jail and prison kitchens are food
   establishments and who inspects them. Utah first (R392-100). Closes the pending line on
   /authorities/fda-food-code-2022/.
3. **ICE standards applicability.** Which facilities are held to NDS 2019 vs. PBNDS 2011 (rev.
   2016), from ICE's own detention-standards pages. Closes the pending line on
   /authorities/ice-nds-2019-food-service/.
4. **BOP.** Current Food Service Manual program statement (P4700.06 vs. P4700.07) and its pest
   provisions; full text of P1600.11 Chapter 3, Section 10 "Pest Control". bop.gov returned a
   404 page to a direct download on 2026-09-24; read through a browser.
5. **Utah county jail standards.** What is public (Utah Code Title 17 Ch. 22; Utah Sheriffs'
   Association statement; any county-published adopted standards) and what the public text says
   about pests and sanitation.
6. **Utah staff pesticide use.** Which R68-7 license, if any, applies to a county or state
   corrections employee applying general-use products inside a facility. Closes the pending line
   on /authorities/utah-r68-7-pesticide-applicator/.

Research prompts R1 (federal), R2 (states and Utah), and R3 (litigation and enforcement record)
are in the Falcon Pest Control project doc `claude/CPR_Build_Plan_2026-09-24.md`.
